## Milestone Exit Criteria
- **M0**: Play a SNES test ROM 10 min on Win/macOS/Linux: no crackle, no stutter, save/load state works, SRAM persists.
- **M1**: Scan 500 ROMs < 10 s; click Play launches runner; playtime recorded.
- **M2**: Cover art for ≥ 90% of No-Intro-matched games; Library scroll 60 fps.
- **M3**: Per-game config overrides; CRT shader on; run-ahead 1 frame stable.
- **M4**:
  - Remap: all 12 SNES buttons rebindable for keyboard and gamepad in launcher Settings; a per-game override of one action leaves the others global (launcher/runner `--print-config` parity); a remapped layout plays with keyboard, an Xbox pad and a PS pad.
  - Hotkeys: all 8 hotkeys rebindable on keyboard and pad; the launcher never creates a conflict (steal); a hand-edited conflict resolves hotkey-wins with a warning; Esc and Guide always open the pause menu (rejected as bindings).
  - Reset game: pause menu → Reset game → Yes soft-resets the core; SRAM unchanged, frames continue, rewind history empty, game back at boot.
  - Resume: every clean exit writes `auto.state/json/png`; next Play (mode `ask`) offers Continue / Start fresh; Continue restores the exact state; Start fresh keeps in-game saves; a newer `.srm` warns; sessions under about 10 s (600 frames) or ended by an error keep the previous resume point.
  - `cargo clippy -D warnings`, `cargo test`, `npm run build` + typecheck green on Windows.
- **M6**:
  - Mixed nested folder (SNES + NES + junk + `.nes` without header + `ROM/NES/x.sfc`) scans each file to the right system regardless of folder names; junk ignored, headerless `.nes` reported (automated).
  - NES No-Intro match for headered and re-headered dumps with metadata (automated, fixture DAT); NES covers from the NES thumbnails repo (manual, online).
  - Play an NES game from the launcher on Mesen with no system/core literals in launcher code (`scripts/check-system-literals.*`, CI); SRAM, save/load state, run-ahead 1 and rewind work (automated on `nostyra-test.nes`, manual on a real game).
  - Move to another folder (either scan order) and rename keep history, favorite, metadata edits, save folder and game config (automated); duplicates stay separate rows.
  - Library system filter + badges, Controls shows 8 buttons for NES (manual); fmt, clippy, tests, UI build + typecheck green on Windows.
- **M7**:
  - Mixed folder with `.gb`, `.gbc`, `.gba`, SNES, NES, junk, a `.gb` without the logo bytes and a `.gba` without `0xEA` at byte 3: each file to the right system, bad files reported as scan failures (automated).
  - No-Intro match + metadata for one entry per new system (automated, fixture DAT); covers from each thumbnails repo (manual, online).
  - Play GB, GBC and GBA from the launcher on mGBA with no new system/core literals outside `system-catalog` (literal gate, CI); SRAM persists with a stable `.srm` size, save/load state, run-ahead 1, rewind (automated on `nostyra-test.{gb,gbc,gba}`); the GB clock keeps running across restarts via `rtc.bin` (automated on the test ROM); a real RTC game keeps its clock (manual).
  - Library system filter usable with 5 systems; Controls 8 buttons for GB/GBC, 10 with L/R for GBA (manual); `zfast-lcd` selectable at 60 fps (manual); fmt, clippy, tests, UI build + typecheck green on Windows.

  - Identification: track-1 SHA1 → DAT title; serial-only → file title + DAT metadata; relink after move by SHA1; rematch by stored serial (automated, fixture DAT + vendored data).
  - Play from the launcher on PCSX ReARMed with no new literals outside `system-catalog`; card 1 persists unchanged at 128 KiB without `.bak`, card 2 in the game folder, save/load state, run-ahead 1, rewind, disc swap on the test `.m3u` (automated, HLE, test discs).
