# Nostyra — Changelog

## 2026-10-29 — Release process
- Branch model: `dev` (local work) → `main` (one commit per release, pushed with tag). `scripts/release.ps1 <version>` creates the release commit with dev's exact tree + annotated tag; never pushes. Guide: `docs/deployment-guide.md`. Repo: https://github.com/vivusk/nostyra.
